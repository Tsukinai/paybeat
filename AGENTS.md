# PayBeat (薪跳)

macOS menu bar app (Swift, SwiftUI + AppKit, macOS 15+) that shows today's earnings second by second, plus a WidgetKit extension. Features and usage: `README.md`.

## Workflow

- Work directly on `main`. Do not create feature branches or worktrees for this repo; this overrides any global branch-per-task rule.
- When a change is done and verified, commit and push to `origin/main` without asking. Conventional Commits with a scope, e.g. `fix(widget): ...`; stage specific files.

## Layout

- `Sources/PayBeat/`: the app. `Widget/PayBeatWidget.swift`: the widget extension ("今日已赚" and "汇率" widgets).
- The widget target also compiles `Config`, `Format`, `Salary`, `Holidays` and `Model` from `Sources/PayBeat/`. Code in those files must build in both targets; a new file the widget needs goes into the widget's `sources` in `project.yml`.
- `project.yml` is the source of truth. `PayBeat.xcodeproj` is generated by `xcodegen` and gitignored.

## Build and install

- `./install.sh`: Release build with Xcode, installs `/Applications/PayBeat.app` and relaunches it. Needs Xcode and xcodegen.
- `./release.sh`: universal build, packaged as `.build/PayBeat-<version>.dmg`.
- Version bumps go into both `Info.plist` and `Widget/Info.plist` (`CFBundleShortVersionString`, `CFBundleVersion`); keep the two identical.
- There is no test suite. Verify a change by running `./install.sh` and checking the real app and widgets.

## Data

- App and widget share `~/.config/work-ticker/`: `config.json`, `rate.json`, `holidays/<region>-<year>.json`. The app writes them; the sandboxed widget reads them through the read-only exception in `Widget/Widget.entitlements`.
- Build paths from `configDir` (based on `realHome`). Inside the widget, `homeDirectoryForCurrentUser` is the sandbox container.
- The widget does no networking. The app calls `WidgetCenter.shared.reloadAllTimelines()` after saving settings and after fetching rates or holidays.

## Localization

- UI strings go through `L("中文原文")`: the key is the Simplified Chinese text, and the `zh-Hans` and `zh-Hant` tables are empty. Add every new key to `Localization/en.lproj/Localizable.strings`.

## Debugging widgets

- Logs: `/usr/bin/log show --last 30m --style compact --predicate 'process == "chronod" AND eventMessage CONTAINS "local.workticker"'`. Use the full path; zsh has a `log` builtin.
- A blank or stale widget with `Bundle version did not match` in the chronod log means more than one copy of the app is registered with LaunchServices. List copies with `pluginkit -mAvvv -D -i local.workticker.widget`. `install.sh` unregisters the build product; unregister any other copy with `lsregister -u <path>` (`/System/Library/Frameworks/CoreServices.framework/Frameworks/LaunchServices.framework/Support/lsregister`).
